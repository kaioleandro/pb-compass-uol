# Olá! Bem vindo aos meus testes do back da aplicação.

### Antes de tudo, é importante ressaltar que a aplicação já deve estar sendo executada localmente no seu dispositivo. Garanta que seu terminal esteja aberto dentro de **cinema-challenge-front** e execute `npm start`.
### IMPORTANTE: Para os testes no front, tenha em mente que o sistema deverá estar com duas instância em execução: tanto no front quanto no backend. Portanto, é importante que execute as instruções presentes no diretório **cinema-challenge-back**, desde a execução do sistema (`npm start`) até o seed da aplicação com os comandos **node** localizados no README do `cinema-challenge-back` (O seed somente em caso de não ter sido realizado ainda).
---
## ORDEM DE EXECUÇÃO:
### Dentro dessa pasta, existem dois arquivos de teste, um depende do outro para o bom funcionamento, portanto, execute-os na seguinte ordem:
1. **test_sistema.robot**
2. **test_sessoes.robot**

## COMO EXECUTAR:
1. Para executar os testes, acesse esse diretório no seu terminal.
2. Realize o seguinte comando: `robot test_sistema.robot`
3. Para a próxima execução, realize o seguinte comando: `robot test_sessoes.robot`
