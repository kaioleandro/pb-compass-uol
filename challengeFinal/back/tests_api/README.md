# Olá! Bem vindo aos meus testes do back da aplicação.

### Antes de tudo, é importante ressaltar que a aplicação já deve estar sendo executada localmente no seu dispositivo. Portanto, é importante que execute as instruções presentes no diretório **cinema-challenge-back**, desde a execução do sistema (`npm start`) até o seed da aplicação com os comandos **node** localizados no README do **cinema-challenge-back**.
---
1. Para executar os testes, acesse esse diretório no seu terminal.
2. Realize o seguinte comando: `robot --outputdir Resultados suites/*.robot`
3. Será criado uma pasta **Resultados** com o log de resultados dos testes.
4. Caso algo dê errado, a pasta `ResultadoSalvo` possui um log próprio, com os testes mais recentes realizados. Apenas altere o final da URL para: `ResultadoSalvo\log.html`.
